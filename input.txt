Uploading#
The standard file upload method is ideal for small files that are not larger than 6MB.

It uses the traditional multipart/form-data format and is simple to implement using the supabase-js SDK. Here's an example of how to upload a file using the standard upload method:
Though you can upload up to 5GB files using the standard upload method, we recommend using TUS Resumable Upload for uploading files greater than 6MB in size for better reliability.

```Python
response = supabase.storage.from_(bucket_name).upload('file_path', file)
```

-- Overwriting files
When uploading a file to a path that already exists, the default behavior is to return a 400 Asset Already Exists error.
If you want to overwrite a file on a specific path you can set the upsert options to true or using the x-upsert header.


```Python
response = supabase.storage.from_(bucket_name).upload('file_path', file, {
  'upsert': 'true',
})
```

-- Content type
By default, Storage will assume the content type of an asset from the file extension. If you want to specify the content type for your asset, pass the contentType option during upload.


```Python
response = supabase.storage.from_('bucket_name').upload('file_path', file, {
  'content-type': 'image/jpeg',
})
```

-- Resumable Upload (bucket-supabase) @web https://supabase.com/docs/guides/storage/uploads/resumable-uploads
The resumable upload method is recommended when:

Uploading large files that may exceed 6MB in size
Network stability is a concern
You want to have progress events for your uploads

```Python
from io import BufferedReader
from tusclient import client
from supabase import create_client
import os

access_token = os.getenv(SUPABASE_ACCESS_TOEKN)
def upload_file(
    bucket_name: str, file_name: str, file: BufferedReader, access_token: str
):
    # create Tus client
    my_client = client.TusClient(
        f"{supabase_url}/storage/v1/upload/resumable",
        headers={"Authorization": f"Bearer {access_token}", "x-upsert": "true"},
    )
    uploader = my_client.uploader(
        file_stream=file,
        chunk_size=(6 * 1024 * 1024),
        metadata={
            "bucketName": bucket_name,
            "objectName": file_name,
            "contentType": "image/png",
            "cacheControl": "3600",
        },
    )
    uploader.upload()

# create client and sign in
supabase = create_client(supabase_url, supabase_key)

# retrieve the current user's session for authentication
session = supabase.auth.get_session()

# open file and send file stream to upload
with open("./assets/40mb.jpg", "rb") as fs:
    upload_file(
        bucket_name="assets",
        file_name="large_file",
        file=fs,
        access_token=session.access_token,
    )

```

1. Store the chat history in PostgreSQL database
2. Use the PostgresSaver to store the chat history with langchain

```python
import os
from dotenv import load_dotenv
from psycopg_pool import ConnectionPool
from langchain_postgres import PostgresSaver
from langchain_core.messages import HumanMessage, AIMessage
from langchain_core.runnables import RunnableConfig

# Load environment variables from .env file
load_dotenv()

# Build the connection string from environment variables
DB_USER = os.getenv("SUPABASE_DB_USER")
DB_PASSWORD = os.getenv("SUPABASE_DB_PASSWORD")
DB_HOST = os.getenv("SUPABASE_DB_HOST")
DB_PORT = os.getenv("SUPABASE_DB_PORT")
DB_NAME = os.getenv("SUPABASE_DB_NAME")

# Supabase connection string format
DATABASE_URL = f"postgresql://{DB_USER}:{DB_PASSWORD}@{DB_HOST}:{DB_PORT}/{DB_NAME}"

def setup_and_use_postgres_saver():
    # 1. Create a connection pool (recommended for production)
    # The PostgresSaver can accept a connection pool object directly.
    pool = ConnectionPool(conninfo=DATABASE_URL, max_size=20)
    
    # 2. Instantiate the PostgresSaver
    # Note: PostgresSaver is also known as PostgresCheckpoint
    memory = PostgresSaver(sync_connection=pool)

    # 3. Create the necessary tables in Supabase (only needs to be run once)
    # The tables will be created if they do not exist.
    print("Creating tables if they don't exist...")
    with pool.getconn() as conn:
        memory.create_tables(conn)
    pool.putconn(conn) # Manually return the connection acquired via getconn() if not using 'with' on the connection itself

    print("Tables created successfully.")

    # 4. Define a specific 'thread_id' to manage a conversation
    # This ID is essential for the saver to track the correct conversation history.
    thread_id = "my_unique_conversation_thread"
    config = RunnableConfig(configurable={"thread_id": thread_id})

    # 5. Add messages to the conversation
    print(f"Adding messages to thread ID: {thread_id}")
    # The 'put' method automatically saves the state to the database
    memory.put(
        config,
        {
            "messages": [
                HumanMessage(content="Hi there! I need help with my Supabase setup."),
                AIMessage(content="Hello! I can assist you with that. What's the issue?"),
            ]
        },
    )

    # 6. Retrieve the conversation history
    print(f"Retrieving conversation for thread ID: {thread_id}")
    checkpoint = memory.get(config)
    messages = checkpoint.get("messages", [])

    print("\n--- Conversation History ---")
    for msg in messages:
        print(f"{type(msg).__name__}: {msg.content}")
    print("----------------------------\n")

    # 7. Close the connection pool when the application is done
    pool.close()
    print("Connection pool closed.")

if __name__ == "__main__":
    setup_and_use_postgres_saver()
```
