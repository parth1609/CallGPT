# Voice Module

FastAPI Voice Module for Speech-to-Text (STT) and Text-to-Speech (TTS).

## Features

- **STT (Speech-to-Text)**: Transcribes WAV, MP3, and other audio formats using the Groq Whisper API.
- **TTS (Text-to-Speech)**: Converts text into premium raw PCM/MP3 audio using the Edge TTS async library.

## Dependencies

- `fastapi`
- `groq`
- `edge-tts`
- `pydub`
